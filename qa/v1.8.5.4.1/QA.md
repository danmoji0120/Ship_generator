## Performance — measured, same machine / Order / Seed

No other test/browser job was active during the final measurement. Node timings use one warm-up planner pair and three alternating measured pairs; full generation uses three alternating same-order pairs after warmup. [Raw compact measurements](performance.json).

| CPU / Normal render metric | Before | After |
|---|---:|---:|
| Slot planning median | 459.5ms | 1107.6ms |
| Candidate trials | 487 | 2,151 |
| Full generation median | 5202.7ms | 5728.0ms |
| Normal Draw Calls | 30 | 30 |
| Normal Triangles | 26,314 | 26,314 |

Whole generation cost increased **10.1%**; planning itself is more expensive because XL/L and both members are actually evaluated rather than skipping XL and imposing L/M quotas. This is not a speed optimization claim. Spatial scene/slot indexes are reused, candidate keys deduplicate, row blocks and existing bounds constrain search. No large optimization framework or unlimited backtracking was added. Debug-only measured outlines/Pair/Battery lines add a bounded number of batches; they do not affect Normal runtime geometry.

GPU timing and physical/mobile hardware performance were not measured. Browser visual checks used Chromium/SwiftShader.

## Safety / preserved authority / limitations

Hull, connectors, production armor/coverage, engines, installed weapon layout/poses/firing arcs, Meso, functional prefabs, requirements and exterior kit data match the same-input baseline. New generator version and empty-slot plan are the intended changes. Surface Normal, same-host coherent contact, internal containment, oriented overlap, real solid interference, existing firing samples, sensor rays, access columns, protected openings and finite per-host support budget are retained; no tolerance was loosened.

Candidate selection remains bounded greedy row ordering, not globally optimal packing. A longer feasible battery or a better large-slot arrangement might exist beyond sampled candidates. Contacts/firing safety use the existing sampled checks and intersections, not complete CSG / exhaustive continuous collision proof. Arbitrarily rotated StructuralVolume support remains outside the existing surface contract. Small interfaces can remain in useful edge/remaining regions; this patch is not equal-per-region distribution or forced symmetry on asymmetric sources. A synthetic flat installation fixture is not a shippable hull result.

See [design/data contract](../../docs/LARGE_FIRST_HARDPOINTS.md). Commit contains compact reports/review sheets and reproducible QA helpers; full local Blueprint/PNG outputs stay preserved and ignored. Original user drafts and historical QA are untouched. No Push is authorized or performed.
