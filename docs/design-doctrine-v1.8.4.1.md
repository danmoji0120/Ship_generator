# V1.8.4.1 — Ship Design Doctrine & Armament Planning

## 이전 경로의 문제

`productionWeaponComposition`은 함종별 `roleScale`, Firepower/Missile의 예산 보너스와 `round(length / 24)` 수량 상한을 사용했다. 주포 → 측면 → 복부 → 미사일 → 방어 순서로 설치하면서 예산이 소진되면 뒤의 그룹을 버렸다. 질량 등급, 추진·항속·센서 예약과 무장 간 자원 경쟁, 다른 구성으로 바꾸는 재계획은 없었다. XL은 축무장 Hardpoint가 있으면 실제 규격 수용 여부와 무관하게 설치된 것으로 집계했다.

## 함종 교리

| 함종 | 주무장 / 구성 목표 | 대형 정책 / 배치 | 설비 투자 특성 |
|---|---|---|---|
| Corvette | S급 전방 함포, 미사일 타격 쌍, 근접방어 | L/XL 금지, 작은 분산 그룹 | 추진 우선 |
| Frigate | M급 호위 포대, 방어막, 센서 | 조건부 L, 상하·측면 방어 | 항속·센서 |
| Destroyer | M급 양용 포대, 미사일 뱅크 | 조건부 L, 측면 포대 우선 | 추진·센서 |
| Cruiser | L급 주포와 M급 다목적 보조 | L 선호, 상부 주포·하부/측면 지원 | 독립 운용·항속 |
| Battlecruiser | 전방 L급 타격, 제한된 보조 화력 | L 선호, 이동에 불리한 측면 질량 억제 | 추진, 장갑 절충 |
| Battleship | 다중 L급 축 포대와 근접방어 | L 선호, 보호 포대·측면 지원 | 장갑 우선 |
| Missile Ship | 발사기 중심, 소수 함포와 방어막 | L/XL 금지, 상하/측면 분산 발사 | 탐지·항속 |
| Spinal Gun Ship | 수용 가능한 XL 축무장, 방어/미사일 지원 | 원래 XL 규격과 축 개구부 필요 | 축무장 예산 예약 |
| Patrol Ship | S급 억제 화력, 최소 미사일, 방어막 | L/XL 금지 | 장기 항속·감시 |

교리는 주포 규격, 범주별 투자 비중, 방향 순서, 대형 무장 허용 조건, 설비 자원 수요가 서로 다르다. 목표는 실물 설치 보장이 아니다. 축 개구부가 없거나 축 구조물이 XL Envelope를 담지 못하는 Spinal Gun Ship은 목표/실제 차이와 생략 사유를 남긴다.

## 유한 자원과 단위

Station Ring을 적분한 모듈 체적을 사용한다. 실제 내부 구획을 모델링하지 않으므로 겹치는 모듈, 구조·통로·배관을 감안해 48%를 사용 가능한 체적으로 잡는다. 전체 질량 한도는 체적 × 0.28 t/m³ × 등급 계수(Light 0.65, Standard 1, Heavy 1.4, Superheavy 1.85)다. 같은 Hull의 등급을 바꾸면 질량 한도만 바뀐다. 생성 주문에서 등급은 기존 Macro에도 영향을 준다.

구조, 추진, 장갑, 항속, 센서, 무장의 수요를 합산해 한도 안에서 정규화한다. 여섯 Priority가 모두 높아도 자원이 늘어나지 않는다. Mobility/Endurance/Sensor 수요가 커지면 무장 몫이 줄어든다. Firepower/Missile은 공통 무장 몫을 늘리면서 그 몫 안에서도 함포와 발사기가 경쟁한다. Survivability는 장갑과 근접방어로 자원을 나눠 쓴다.

- 무장 질량은 공통 규격 Cost × 240 t × 규격 Scale³ × max(1, (length/40)^1.5), 미사일은 1.15배다. 탄약·구동·정비·장거리 지원을 포함하는 **설계 비용 모델**이며 물리 시뮬레이션 값은 아니다. 규격을 변경하거나 축소하는 데 사용하지 않는다.
- 무장 체적은 규격 Envelope 체적의 85%, 미사일은 탄약고를 포함해 135%다. 장착 면적은 Footprint의 125%를 예약한다. 실제 Foundation, OBB, 고체 충돌 및 사격 공간은 별도로 검증한다.
- 기존 장갑의 실측 고체 체적에 유효 복합/중공 밀도 0.12 t/m³, 내부 침범 체적 12%를 적용한다. 예약보다 크면 완성된 장갑을 보존하고 무장 몫을 줄인다. 전체 한도를 넘으면 후보를 명시적으로 거부한다.
- 구조·추진·연료/열관리·정비·센서의 `usage`는 내부 설비를 위한 **예약 사용량**이다. 실제 기능 외장 조립체의 고체 체적/질량은 `equipment`에 따로 기록한다. 예약과 외장 고체 비용을 이중 합산하지 않는다. 외장 설비도 분야 예약을 초과하면 설치하지 않는다.

표면은 노출 Hull 삼각형의 보호 개구부 제외 면적과, 모듈별·방향별 5×8 격자의 실제 최종 장갑 S급 Foundation 접촉 검사로 평가한다. 성긴 격자는 추정치이므로 실제 합격한 설치 후보가 그 사이에 있으면 `verifiedCandidateM2`로 최소 수용 면적을 보정한다. 집계 면적만으로 설치를 허용하지 않는다. 각 후보는 17점 접촉, 대칭 접촉면, Foundation/장비 충돌, 개구부/정비 채널, 양쪽 무장의 사격 공간을 통과해야 한다. 각 모듈의 내부 무장 체적 몫도 따로 검사한다. 외부 포탑 Envelope 전체를 내부 점유로 이중 계산하지 않는다. 내부 점유 비율은 함포 25%, 근접방어 12%, 미사일 65%, XL 100%이며 전체 Envelope/지원 체적은 전역 무장 예산에서 그대로 제한한다.

## 구성 목표와 재계획

1. 주문서/교리로 CANNON/MISSILE/POINT_DEFENSE 투자 비중과 S/M/L 목표를 정한다. 구조물의 폭·높이·길이, 규격 Envelope, 질량·체적·표면 예산으로 수량을 제한한다. `length / 24`를 사용하지 않는다.
2. 중요 그룹부터 원래 규격, 별도의 더 작은 **표준 규격 대체 그룹**, 대칭 측면 대체, 소형 지역 방어 대체를 탐색한다. L/XL 자체 치수는 그대로다. XL은 축 구조물과 예산이 충족되어야 하며 표면 포탑으로 취급하지 않는다.
3. 각 대체안은 최대 7개 길이 방향 위치를 검사해 최대 2개의 합격 Pose를 보관한다.
4. 최대 6개 상태의 Beam Search가 그룹 채택/생략을 함께 비교한다. 점수 상위, 비용 효율, 미투자 분기를 보존해 앞 그룹이 후속 그룹의 모든 가능성을 막지 않게 한다. 주포 체급 충실도, 범주 투자, 방향 커버리지를 평가하고 배치 충돌은 상호 검사한다.
5. 선택된 그룹을 통째로 저장한다. 대체·재계획·생략과 원래 목표 대비 차이를 남긴다. `weaponLayout.attempts.variant`는 각 대체 그룹과 후보 Hint를 보존한다. `accepted`는 물리 후보 검사 통과, `selected`는 실제 채택 여부다. 계산량이 제한된 검색이며 전역 최적해 보장은 아니다.

## Blueprint / UI / 보존

`designDoctrine.version: "1.8.4.1"`는 Schema 2에 추가된 선택적 필드다. 역사적 Blueprint에 교리를 소급 생성하지 않는다. Macro/Production 기본 계약의 `generatorVersion`과 `pipelineVersion`은 "1.8.4"를 유지해 기존 소유권/렌더링 경로를 보존한다. UI 릴리스는 V1.8.4.1이며 Inspector의 펼침 영역에서 목표, 실제, 자원 예약/사용, 방향별 잔여 면적과 생략 사유를 읽을 수 있다.

Blueprint는 교리 목표, 전체/분야별 예산, 실제 장갑 비용, 설비 고체 비용 및 `equipmentTargets`의 목표/실제 수량·물리적 생략 이유, 목표/실제 무장, 대체로 추가된 규격까지 포함하는 차이, 방향별 구성/표면, 모듈별 수용 공간, 검색 비용과 조정 사유를 저장한다. 잔여 면적/체적은 **자원 예산의 잔여**다. 사격 공간이나 표면 굴곡 때문에 추가 무장이 반드시 들어간다는 뜻은 아니다.

L/XL 규격, 기존 M급 외형, Macro/상하부 장갑, TOP/BOTTOM/PORT/STARBOARD, 대칭 그룹, 장갑 보존, Foundation 접촉/충돌/사격 규칙을 유지한다. 새 S급 미사일 발사기는 S급 Envelope 안에 들어가는 별도 구성이다. 전반적인 미술 시스템을 개편하지 않았다.
