# Fragment authority versus visual detail

`beginAuthoritativeDetonation` accepts no visual quality and forces the fixed
HIGH / 256-direction policy. It uses the existing finite carrier engine, game
calibration, chronological ordering, bounded secondary mass/energy and local
DamageInstance ownership. This is not real fragment truth or a multiplayer server.
The existing `beginDetonation` LOW/MEDIUM sampling contract remains available for
explicit laboratory diagnostics and historical experiments.

Visual LOW/MEDIUM/HIGH only selects which existing trajectories and impact marks
to draw. Hidden marks stay in state/history/exports and retain all simulation
effects. Persistent scene buffers have bounded impact display counts; no physical
carrier or damage record is removed to achieve a visual frame budget. The
laboratory's independent scheduled work slices change yielding only; tests and
real Production exports compare complete states and ordered contacts.
